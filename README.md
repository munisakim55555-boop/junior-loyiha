## 📌 About

**Junior-loyiha** is a starter repository for practicing the fundamentals of software development and learning how to manage projects with Git and GitHub.

This repository is intended to grow as new exercises, examples, and project files are added.

## 🎯 Learning goals

- Understand how Git and GitHub repositories work
- Practice making commits and tracking changes
- Organize project files clearly
- Document a project using Markdown
- Build and improve practical development skills
